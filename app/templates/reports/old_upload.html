From an Excel or CSV file

Easiest: download the sample Excel, copy your old orders into its “Orders” sheet in the same columns, and upload it here.

From Google Sheets: File → Download → Microsoft Excel (.xlsx). Old .xls files: open in Excel and “Save As” .xlsx.

Works best with one row per order and a header row such as: Order ID, Order name, Customer, Items, Date, Billed, Cost, Received, Profit. Missing columns are fine; profit is worked out as billed − spent when there is no profit column. If the file has one tab per year, pick the tab on the next screen.
