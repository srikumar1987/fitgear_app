Upload backups and design files straight to your Google Drive, with no Drive app needed on this PC. The app can only see the files it creates, not the rest of your Drive. One-time setup, about 10 minutes, free:

  1. Open console.cloud.google.com with your personal Google account and create a project, e.g. “TUR fitgear”.
  2. APIs & Services → Library: search Google Drive API and click Enable. Do the same for Google Sheets API (used only to read old sheets for Old reports).
  3. OAuth consent screen (Google Auth Platform): app name “TUR fitgear”, your email, audience External. Then under Audience click Publish app, otherwise access expires every 7 days.
  4. Clients → Create client: application type Desktop app, name “TUR fitgear”, then Create and Download JSON.
  5. Choose that file below and click Save client, then Connect Google Drive.

Keep the downloaded JSON file safe (e.g. email it to yourself). To restore on a new PC, use the same Google account and this same file.
